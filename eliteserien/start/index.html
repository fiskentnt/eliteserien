Hvorfor har Start 90 % sjanse for nedrykk?

Start ligger åtte poeng bak Sandefjord på 13. plass og er omtrent like sterke ifølge modellen (4,2 mot 4,2). Aalesund og Kristiansund er også med i kampen om å unngå nedrykk.

I simuleringene ender Start i snitt på 24 poeng mot 33 for Sandefjord, og rykker ned direkte i 90 % av dem.

Hva må Start gjøre for å unngå både nedrykk og kvalik?

Det skal mye til: Start unngår både nedrykk og kvalik i rundt 3 % av simuleringene. De må ta 16 av de 21 poengene som er igjen for å komme opp på 32. Ender de på 32 poeng, er sjansen omtrent 65 %. Med 35 poeng er den over 99 %.

Start når minst kvalikplass i 10 % av simuleringene. De må ta 14 av de 21 poengene som er igjen for å komme opp på 30. Ender de på 30 poeng, er sjansen for minst kvalikplass 64 %.

Hvilken plass ender Start på?

Start ligger på 16. plass med 16 poeng. Matematisk kan de ende fra 5. til 16. plass. Oftest blir det 16. plass (62 %), og i minst 90 % av simuleringene ender de mellom 14. og 16. plass.
