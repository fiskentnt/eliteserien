Hvorfor har Start 83 % sjanse for nedrykk?

Start ligger fem poeng bak Sandefjord på 13. plass og er omtrent like sterke ifølge modellen (4,2 mot 4,3). Aalesund og Kristiansund er også med i kampen om å unngå nedrykk. Start har også et tøffere restprogram: motstanderne har i snitt 49 % vinnersjanse, mot 40 % for Sandefjord.

I simuleringene ender Start i snitt på 26 poeng mot 32 for Sandefjord, og rykker ned direkte i 83 % av dem.

Hva må Start gjøre for å unngå både nedrykk og kvalik?

Det skal mye til: Start unngår både nedrykk og kvalik i rundt 6 % av simuleringene. De må ta 13 av de 18 poengene som er igjen for å komme opp på 32. Ender de på 32 poeng, er sjansen omtrent 69 %. Med 35 poeng er den over 99 %.

Start når minst kvalikplass i 17 % av simuleringene. De må ta 11 av de 18 poengene som er igjen for å komme opp på 30. Ender de på 30 poeng, er sjansen for minst kvalikplass 71 %.

Hvilken plass ender Start på?

Start ligger på 16. plass med 19 poeng. Matematisk kan de ende fra 7. til 16. plass. Oftest blir det 16. plass (50 %), og i minst 90 % av simuleringene ender de mellom 13. og 16. plass.

Har Start tatt flere eller færre poeng enn ventet?

Start har 6 poeng færre enn markedet ventet: oddsene før kampene ga 25 poeng, og Start har 19. Start var favoritt i 5 kamper og vant 2, og underdog i 19 og vant 3. Største overraskelse var seieren hjemme mot Brann 13. september (25 % sjanse for seier). Største skuffelse var tapet hjemme mot HamKam 11. oktober (56 %).

Kampene som er igjen

Start har det 5. tøffeste restprogrammet av 16 lag: motstanderne har i snitt 49 % vinnersjanse. Vanskeligst blir borte mot Rosenborg 7. november, der modellen gir 12 % sjanse for seier.
